# 04 — AI yordamchi

## Vazifasi

- **Har doim mavjud** — Bugun ekranidan ham, alohida AI bo'limidan ham.
- **Qisqa javob** — 3–5 jumla, oxirida bitta aniq qadam.
- **"Qanday ketyapman?"** — foydalanuvchining haqiqiy statistikasini tahlil qilib javob beradi.
- **Kun tartibi tuzish** — onboarding'da va "Ertangi kunni rejalashtir" so'rovida; natija bir bosishda kun tartibiga qo'shiladi.
- **Haftalik AI hisobot** — foydalanuvchi **haftada 1 marta** so'ray oladi.
- Oylik tahlil 🟡.

### Taxminiy xarajat
Bitta chat so'rovi ≈ 1 500 kirish + 250 chiqish token. DeepSeek'da bu ≈ **$0.0007**. Ya'ni 1 000 ta so'rov ≈ $0.70. Haftalik hisobot ≈ $0.0015.
Tekin qatlam kuniga ~2 500 so'rovni yopadi; undan oshgani juda kam pul turadi.

## Router qanday ishlaydi

Barcha provayderlar **OpenAI-mos API** beradi (Gemini'ning ham OpenAI-mos endpointi bor), shuning uchun bitta klient — faqat `base_url`, `model`, `api_key` almashadi.

```
so'rov keldi
 → foydalanuvchi limitini tekshir (Redis: ai:user:{id}:{sana})
 → keshni tekshir (bir xil savol + bir xil statistika)
 → provayderlarni priority bo'yicha aylan:
      o'tkazib yubor, agar: enabled=false | cooldown bor | kunlik cap to'lgan
      so'rov yubor (birinchi token uchun 8 s timeout)
      muvaffaqiyat → javobni oqim bilan qaytar, hisobni oshir, ai_messages ga yoz
      429 / quota  → cooldown (Retry-After yoki kun oxirigacha), keyingisiga o't
      5xx / timeout → 3 marta ketma-ket bo'lsa 5 daqiqa cooldown, keyingisiga o't
      reja so'rovida JSON noto'g'ri → keyingisiga o't
 → hech biri ishlamasa → shablon javob
```

- Cooldown va hisoblagichlar Redis'da: `ai:cooldown:{code}`, `ai:count:{code}:{sana}`.
- Admin paneldan: tartibni o'zgartirish, yoqish/o'chirish, "Test" tugmasi, kunlik grafik.
- API kalitlar faqat serverning `.env` faylida. Ilovaga hech qachon tushmaydi.

## "Qanday ketyapman?" — kontekst

Har bir chat so'roviga server foydalanuvchi haqida **qisqa, anonim** kontekst qo'shadi (~300 token):

```json
{
  "user": {"type": "university_student", "age": 20, "prays": true, "main_goal": "IT kompaniyada ishlash"},
  "today": {"date": "2026-10-16", "done": 5, "planned": 9, "next": "Sport 18:00"},
  "last_7_days": {"score": 72, "prev_score": 64,
    "by_category": {"prayer": 91, "reading": 43, "sport": 57, "study": 80, "language": 70}},
  "streak": {"current": 6, "longest": 14},
  "most_missed": [{"title": "Kitob o'qish", "missed": 4, "usual_time": "05:30"}],
  "best_day": "dushanba", "weak_day": "shanba",
  "sleep_avg": "23:40", "challenge": {"title": "10 kunda 300 so'z", "progress": "180/300", "day": "6/10"}
}
```

Ism, email, ID **yuborilmaydi**. Oliy maqsad matnini yuborishdan oldin foydalanuvchiga sozlamalarda "AI bilan ulashish" tanlovi beriladi (default — yoqilgan, o'chirsa yuborilmaydi).

## Tizim ko'rsatmasi (system prompt) — chat

```
Sen "Dailer" ilovasining yordamchisisan. Vazifang — foydalanuvchiga kun tartibiga
amal qilish va intizomni oshirishda yordam berish.

Qoidalar:
- Foydalanuvchi tilida javob ber (default: o'zbek, lotin yozuvi).
- Qisqa yoz: 3–5 jumla. Ro'yxat kerak bo'lsa — ko'pi bilan 4 band.
- Faqat KONTEKST dagi raqamlarga tayan. Raqam o'ylab topma. Ma'lumot yetmasa, ayt.
- Avval yaxshi tomonini ayt, keyin bitta zaif joyni, oxirida BITTA aniq qadam taklif qil.
- Uyaltirma, qo'rqitma. Ohang — g'amxo'r ustoz kabi.
- Asosiy g'oya: "24/7 ishlash shart emas — tartib va davomiylik kerak."
- Diniy hukm (fatvo) berma — "imomga murojaat qiling" de. Tibbiy tashxis qo'yma.
- Ilovaga aloqasi yo'q mavzularda qisqa javob berib, mavzuga qaytar.
- Foydalanuvchi o'ziga zarar yetkazish haqida yozsa — hamdardlik bildir va
  ishonch telefoniga / yaqinlariga murojaat qilishni maslahat ber.

KONTEKST:
{context_json}
```

## Reja tuzish — tuzilgan javob

`/ai/plan` modeldan **faqat JSON** so'raydi va Pydantic bilan tekshiriladi:

```json
{
  "mode": "weekday",
  "items": [
    {"title": "Uyg'onish", "category": "sleep", "start": "05:00", "duration_min": 0},
    {"title": "Bomdod namozi", "category": "prayer", "prayer": "fajr"},
    {"title": "Kitob o'qish", "category": "reading", "start": "05:40", "duration_min": 30,
     "target": 20, "unit": "bet", "min_version": "kamida 2 bet"}
  ],
  "tips": ["Darsdan keyin 20 daqiqa dam oling, keyin kurs vazifasiga o'ting."]
}
```

Tekshirish: vaqtlar kesishmaydi, uyqu vaqti hurmat qilinadi, namoz vaqtlari serverda hisoblangan haqiqiy vaqtga moslanadi. Yaroqsiz bo'lsa — keyingi provayder.

Onboarding'da AI 1–2 ta aniqlashtiruvchi savol bera oladi (masalan "Kursingiz qaysi kunlari?"), keyin rejani tuzadi.

## Haftalik hisobot

- Foydalanuvchi [AI haftalik hisobot] ni bosadi → shu hafta uchun `ai_reports` da yozuv bo'lsa, **o'sha qaytariladi** (qayta generatsiya yo'q).
- Tuzilishi: 1) umumiy baho va o'tgan haftadan farq, 2) eng kuchli 2 tomon, 3) eng zaif 1–2 joy va sababi (vaqt/kun bo'yicha), 4) keyingi hafta uchun 3 ta aniq qadam, 5) oliy maqsad bilan bog'lovchi bitta jumla.
- Dushanba ertalab xabar: "O'tgan hafta natijangiz tayyor — AI tahlilini oling."

## Sifatni nazorat qilish

- Ishga tushirishdan oldin **20 ta o'zbekcha test savol** (turli foydalanuvchi turlari, turli statistika) bilan har bir provayder sinab ko'riladi. Natijaga ko'ra tartib belgilanadi.
- `ai_messages` da har javobga 👍/👎 qo'shiladi; admin dashboard'da provayderlar bo'yicha qoniqish foizi.
- Har oy provayderlar narxi va limitlari qayta tekshiriladi.
